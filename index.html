Homelab Backups

A private, single-household tool for encrypted backups of self-hosted application data and configuration.

Restic encrypts backups locally. Rclone transfers the encrypted repository directly between the household server and the owner’s Google Drive. Google authorization requests only drive.file, covering files created by or explicitly used with this app.

This website provides information only. It offers no login, server access, or access to backup data.
