Privacy policy

Updated 28 October 2026.

Homelab Backups is a personal household tool, not a public backup service. Google Drive access is used solely to upload, read, verify, restore, and remove encrypted backup repository files according to the owner’s retention settings.

The app requests the Google Drive drive.file permission. It does not request access to unrelated existing Drive files. OAuth credentials and refresh tokens are stored on the owner’s server with restricted file permissions. The backup encryption password is kept separately from the cloud repository.

Data transfers occur directly between the owner’s server and Google. No advertising, sale of user data, analytics, or AI training is performed by this tool. Google and GitHub process information under their own policies. GitHub hosts this information website and may collect standard request metadata.

Google account data is used only for the backup functions described here, following the Google API Services User Data Policy, including its Limited Use requirements. The owner can revoke authorization in Google Account settings, remove credentials from the server, and delete the repository from Drive. Revoking authorization does not itself delete existing backups.

For questions, contact the repository owner using the project issue tracker. Never post credentials, backup contents, or other private data in a public issue.
